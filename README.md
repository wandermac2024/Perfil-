## Publicação
1. Crie um repositório no GitHub, por exemplo `wanderley`.
2. Envie `index.html`, `styles.css`, `script.js` e a pasta `assets`.
3. Abra `Settings > Pages`.
4. Escolha `Deploy from a branch`.
5. Selecione `main` e `/ (root)`.
6. Salve.

O endereço ficará semelhante a:
`https://SEU-USUARIO.github.io/wanderley/`
